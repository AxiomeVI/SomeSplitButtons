# SomeSplitButtons

Inspired by [WonderMods](https://github.com/WonderGinger/WonderMods) Return to Menu split button

## Save and Quit Split
Add a menu button in the pause menu to unpause and split the room timer (after 31 frames) for practicing segments containing a S&Q. By default it then re-enters the room exactly as the game does when a chapter is resumed after a real S&Q. Can be turned off to split without reloading the room.

## Skip Cutscene Split
Add a button in the pause menu to unpause and split the room timer (after 18 frames or 232 for Prologue) for practicing end-of-chapter cutscene skips as if under filetime condition.

## Return to Map Split
Add a button at the bottom of the pause menu to unpause and split the room timer (after 31 frames) for practicing segments ending with a Return to Map.

## Berry Collect Protection
Leaving a chapter with a red berry still collecting loses it, so by default the Save and Quit and Return to Map splits refuse to fire and tell you how many frames the berry still needs. Can be turned off to split anyway.
