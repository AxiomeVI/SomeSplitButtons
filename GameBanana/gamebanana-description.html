Some Split Buttons

Pause-menu buttons that split SpeedrunTool's room timer where a real Save and Quit, Return to Map or end-of-chapter cutscene skip would, so you can practice those segments without leaving the level. Inspired by the Return to Map Split of WonderMods.

Each button waits as long as the real action takes before splitting. Save and Quit and Return to Map keep the game paused during that wait, like the real buttons.

Turn each button on or off in Mod Options → Some Split Buttons. Requires SpeedrunTool.

Save and Quit Split

Splits after 31 frames, the fade-out animation, then reloads the room like a real Save and Quit. Turn off Then Reload the Room to split without reloading: the chapter clock then waits until you regain control of Madeline.

Return to Map Split

Asks for confirmation, then splits after 31 frames. Turn on Then Load a Checkpoint to pick a checkpoint and keep running from there: the timer resumes once you regain control of Madeline.

Skip Cutscene Split

Appears during end-of-chapter cutscenes. Splits after 18 frames (232 in Prologue), the fade-out of a skipped cutscene, so you can practice ending skips on file time.

Collect protections

Save and Quit and Return to Map refuse to split while a crystal heart or a red berry is still being collected, and show how many frames are left. Berry protection can be turned off with Berry Collect Protection.
